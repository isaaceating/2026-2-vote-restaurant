# 2026 下半年部門聚餐餐廳票選

沿用上一期餐廳票選風格的獨立靜態網站。無套件、無資料庫、無留言功能。

## 更新活動

編輯 `config.js` 的聚餐日期、投票截止日與 Google 表單作答連結。表單連結尚未設定時，投票按鈕保持停用，不會導向舊表單。

餐廳內容與照片來源集中於 `app.js`。日期目前為 TBD，暖肴價位待確認。

## 部署

GitHub Pages 使用 main 分支的根目錄。新 Google 表單作答連結已填入 `config.js`；表單已發布，作答範圍為 Lumens Digital Optics Inc.，收集已驗證電子郵件。

## 資料與照片

2026-10-06 查核；餐廳卡片附上來源。照片由外部來源載入，載入失敗時保留餐廳名稱與漸層背景。

- 客家本色竹北：地址由店家訂位頁核對，均消約 NT$500 參考愛食記；照片為店家 Uber Eats 頁面及雞蛋糕竹北店食記。
- 彼刻：地址、特色與義大利麵價位參考官方網站／菜單；三張照片為竹亭聽雨 2025 食記中的義大利麵與鴨胸餐點。
- 暖肴聚所：地址及特色參考葛朗餐飲官方網站。照片為台菜餐點、共用庭院入口與建築外觀實拍，不採用官方標示為 ChatGPT Image 的圖片。
- 呷奔來坐：地址核對 Gomaji 與卡爾茗食記，價位 NT$300–500 為 2024 食記參考；照片来自 Gomaji 店家頁。

公開價格並非本次團體報價。外部照片權利屬原作者，來源連結不代表取得授權；需要自行持有的照片時可替換圖片網址。

每家餐廳三張照片；點擊整張照片或右上角編號可循環切換 1 → 2 → 3 → 1。兩個切換控制皆為原生按鈕，支援鍵盤 Enter／Space 操作。
